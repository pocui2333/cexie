# EchoLens (语镜) 终极系统架构与数据管道全景白皮书 (Master System Architecture Blueprint)

> **版本**：v2.0.0 (Master Architecture Blueprint)  
> **项目名称**：EchoLens (中文名：语镜)  
> **定位标语**：微感双轨言语孪生镜像系统 (macOS WeChat Copilot)  
> **设计哲学**：单目标沙盒物理隔离 + 实体关联记忆网络 (Chatless) + 纯鼠标驱动极简透明 HUD + 双轨渐进进化  
> **核心承诺**：彻底剔除悬浮窗内手打输入与模拟发送负担，全系统 100% 纯鼠标点按，零键盘快捷键冲突，零 Emoji，零外部图标库，免切屏，真纯粹，能进化

### 四大核心哲学：
1. **微信备注物理沙盒 (Strict Contact Sandboxing)**：
   一个微信聊天框对应一个独立物理目录，不同联系人的故事线、人际网、说话禁忌绝不跨域混淆。
2. **聊天记录不留底 (Chatless Memory Stream)**：
   微信原话只在内存中充当原材料，提炼出 Episode 纯事实流后，原始文本物理销毁，无隐私隐患，存储永不膨胀。
3. **实体关联记忆唤醒 (Entity-Linked Memory)**：
   配角（如老李、室友、同事）不单独建档，内嵌在主角的世界中打上实体标签。主角一开口提人名，毫秒级翻出旧账。
4. **双轨渐进进化 (Dual-Track Incremental Evolution)**：
   左栏 3 条忠实于原生本真习惯（保底不出错）；右栏 3 条外接策略战术知识库注入 15% 沟通微调（微调温度与推进），润物细无声完成人设进化。

## 二、 文件夹智能扫描与数据解析管道 (Folder Ingestion & Parsing Pipeline)

针对用户导入已有聊天记录时“通常是包含多个年份、多种格式的完整文件夹”这一现实，系统设计六阶全自动解析管道：

```text
用户拖入整个文件夹: 【示例好友_历史记录/】
  ├── 2024_chat.csv
  ├── 2025_chat.csv
  ├── 2026_export.txt
  └── images/ (多媒体附件)
        │
        ▼ 阶段 1: 格式探测与多源归一化 (Discovery & Normalization)
        │  • 递归扫描子目录，自动识别 CSV / TXT / JSON
        │  • 统一提取四元组: (timestamp, sender, content, msg_type)
        │
        ▼ 阶段 2: 全局时序对齐与多文件去重 (Chronological Fusion & Deduplication)
        │  • 跨年份、跨文件基于时间戳与消息内容哈希合并
        │  • 自动识别并剔除完全重复或时间重叠的记录
        │
        ▼ 阶段 3: 连珠炮多句聚合与会话切片 (Turn Aggregation & Episode Slicing)
        │  • 同一人 60 秒内连续发的短句合并为一条完整发言
        │  • 双方静默超过 2 小时的间隙切分为一个独立的【情境候选块 (Episode Window)】
        │
        ▼ 阶段 4: 大模型情境脱水萃取 (LLM Episodic Distillation)
        │  • 提取: 主题、涉及实体 (Entities)、3~5条核心事实、关系动态
        │  • 剔除: 废话、语气词、日常口水话
        │
        ▼ 阶段 5: 四重持久化分发 (Four-Fold Storage Dispatch)
        │  • 分发 1: 写入 dossier.md (终身大事记)
        │  • 分发 2: 写入 episodes.md (情境事件清单)
        │  • 分发 3: 统计语言习惯写入 rules.json (平均句长/表情统计)
        │  • 分发 4: 写入 index.db (实体与时间索引)
        │
        ▼ 阶段 6: 原始数据粉碎 (Chatless Destruction)
           • 立即解除原始历史文件关联，不留存冗余原始记录
```

### 1. 多源格式兼容矩阵
| 文件类型 | 特征模式 | 识别与解析策略 | 归一化映射 |
| :--- | :--- | :--- | :--- |
| **标准微信导出 CSV** | 包含标头 `Date, Sender, Message, Type` | CSV Reader 流式读取，过滤系统通知 | `Date -> timestamp`, `Sender -> role`, `Message -> text` |
| **纯文本流水 TXT** | `2025-06-19 14:20:00 示例好友:\n文本内容\n` | 正则匹配时间戳行与发言人行 | 跨行文本自动合并，换行符清洗 |
| **微信留痕/第三方 JSON** | `[{"time": "...", "from": "...", "msg": "..."}]` | JSON 反序列化 | 提取时间、方向、正文 |
| **PC 微信备份 SQLite** | 包含 `messages` 或 `chat_record` 表 | 提取 `CreateTime, Des, Message` | 时间戳换算，解码文本字段 |

### 2. 角色自动判定规则 (Speaker Attribution)
解析器在遍历文件夹时，自动根据发言频次与命名规则识别身份：
* **我方 (Ego)**：凡是备注为“我”、或者匹配用户昵称、或者在双向对话中居于回复位的，统一映射为 `role: "me"`
* **目标 (Target)**：匹配该文件夹所属人名（如“示例好友”），统一映射为 `role: "target"`

## 三、 数据存储沙盒规范 (Storage Sandbox Specifications)

所有数据存放在 `data/` 目录下，彻底实现**以微信备注为命名空间**的物理沙盒隔离：

```text
echolens/data/
├── ego/                                  # 【我】的全局本体
│   ├── profile.md                        # 我方的核心人格底色、价值观、处世哲学
│   └── rules.json                        # 全局硬防线 (逗号流、禁句号感叹号、全局负词库)
│
└── contacts/                             # 【多目标沙盒隔离区】
    │
    ├── 示例好友/                          # 微信备注目录名
    │   ├── dossier.md                    # 核心小传 + 关联人物图谱 (老李/小刘/室友)
    │   ├── episodes.md                   # 脱水故事线 (纯事实情境流)
    │   ├── rules.json                    # 我对 TA 的专属交互偏好 (12~25字、逗号断句)
    │   └── index.db                      # 极轻量 SQLite 索引 (实体标签与关键词快速召回)
    │
    ├── 联系人A/
    │   └── ... (独立 4 件套)
    ├── 联系人B/
    │   └── ... (独立 4 件套)
    └── 常用联系人/
        └── ... (独立 4 件套)
```

## 四、 实体记忆唤醒与双轨决策机制

### 1. 实体记忆唤醒
当对方发来消息时，系统执行毫秒级实体检索，精准唤醒前情提要：
1. **实体识别**：从消息中提取关键词与人名（例如：“我室友今天又跟同事聚餐了” -> `["室友", "同事"]`）
2. **查目标专属 `index.db`**：快速匹配命中的 Episode
3. **前情提要注入**：将历史事实作为 Context 注入生成提示词，使回复具备长期记忆与深层默契

### 2. 双轨 6 选项生成矩阵 (The 2x3 Matrix)

| 栏目分类 | 卡片编号 | 生成依据 | 战术目标 | 语言特征 |
| :--- | :--- | :--- | :--- | :--- |
| **左栏：本真表达** | **[1] 直球承接**<br/>**[2] 事实接话**<br/>**[3] 极简实用** | `data/ego/profile.md`<br/>+ 历史原生语言数据 | 100% 忠实于当前习惯，绝对不出错、绝对真实 | 纯粹北方大白话、逗号流、原生克制与冷幽默 |
| **右栏：进阶微调** | **[4] 增加情绪温度**<br/>**[5] 顺势埋下引子**<br/>**[6] 转换角度关怀** | 外接策略战术知识库<br/>+ **$\Delta \le 15\%$ 渐进进化法则** | 在保留本真底色的前提下，微调 15% 沟通技巧 | 85% 原生大白话 + 15% 策略微调（多一句领情/多一个自然邀约钩子） |
