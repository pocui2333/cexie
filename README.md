# 侧写 (Cexie)

> **macOS 微信桌面辅助副驾驶 · 极简透明悬浮窗 · 智能高情商回复生成**

「侧写」是一款常驻于 macOS 桌面边缘的极简透明悬浮窗工具。在与朋友聊天时，点击即可一键抓取微信对话上下文，并瞬间生成 6 档自然、高情商的回复建议。单击任意卡片即可复制，无键盘冲突，不修改微信客户端。

---

## 核心亮点

- **极简自适应 HUD**：宽度固定 430px，高度随文字内容紧密自适应，底端零留白；点击右上角【折叠】秒缩为 180×36px 边缘微型小胶囊。
- **全鼠标单击即复制 (Click-to-Copy)**：单击任意推荐卡片瞬间写入剪贴板并附带发光反馈，回到微信直接 `Cmd+V` 粘贴发送，零按键冲突。
- **双轨 6 档生成矩阵**：
  - **左栏【直觉原句】（3 档）**：真实大白话、真诚直接、自然松弛、原味接地气；
  - **右栏【微调提升】（3 档）**：适度注入沟通战术（情绪共鸣、化解容貌与打工焦虑、自然留钩子）。
- **物理沙盒与 Chatless 记忆**：以微信备注为独立目录隔离（`data/contacts/{备注}/`）；聊天原话脱水提炼后即刻粉碎，绝不持久化存储聊天原文。
- **灵活的驱动模式**：内置离线高情商启发式引擎；同时支持在 AI 对话框（如 Cursor / Antigravity / Claude Code）内直接接管，或通过 `.env` 接入商业大模型。

## 快速开始

### 1. 环境准备
- 系统：**macOS 12.0+** (支持 Apple Silicon 与 Intel 芯片)
- 环境：**Python 3.10+**，macOS 官方 WeChat 客户端

### 2. 安装与启动
```bash
# 克隆仓库并安装依赖
git clone https://github.com/pocui2333/cexie.git
cd cexie
pip install -r requirements.txt

# 启动程序
python3 app.py
```

> **注意 (首次启动系统权限)**：  
> 首次运行时，macOS 会申请权限，请前往 **系统设置 -> 隐私与安全性**：  
> 1. **屏幕录制**：允许当前终端 (Terminal / iTerm / VSCode) 与 Python；  
> 2. **辅助功能**：允许当前终端与 Python。

## 日常使用

1. **抓取与生成**：在微信中打开目标好友聊天窗，点击悬浮窗上的 **【抓取最新】**，500ms 内自动识别并呈现 6 档回复建议；
2. **复制与发送**：鼠标单击中意的卡片（卡片高亮并提示已复制），在微信输入框按 `Cmd+V` 粘贴发送；
3. **窗口折叠**：点击顶栏 **【折叠】** 收起为微缩胶囊，点击胶囊上的 **【展开】** 恢复全貌；
4. **新建好友档案**：点击顶栏 **【导入建档】**，填写微信备注名与自由描述（如“大学室友，说话互损，多用短句，别整客套话”），提交即可即时创建沙盒。

## 记忆脱水与历史记录导入 (Chatless Engine)

系统追求“多年老友般的默契记忆”，同时严守“不存聊天原文”的隐私红线：

```text
微信对话流 / 历史文件 ──► [ 增量断点 / 多源时序对齐 ] ──► [ 角色切片与去废话 ]
                                                            │
                                                            ▼
                                              [ 结构化事实脱水与实体提取 ]
                                                            │
                                  ┌─────────────────────────┴─────────────────────────┐
                                  ▼                                                   ▼
                         episodes.md (纯事实流)                              index.db (毫秒级索引)
                                  │
                                  ▼
                   【原始聊天文本物理粉碎销毁 (Chatless)】
```

### 1. 实时增量蒸馏 (Incremental Distillation)
- 每次点击【抓取最新】，系统读取沙盒内的 `checkpoint.json` 比对哈希；
- 严格仅提炼上一次记录点至今的新增对话，分清“我说的”与“对方说的”，剔除口水话与语气词；
- 提炼结构化事实（主题 Theme、关联实体 Entities、发生事实 Facts、关系动态 Dynamic）追加写入 `episodes.md` 并入库 `index.db`；
- **提炼完成后，内存中的聊天原句即刻析构，不留任何原文存盘**。

### 2. 历史聊天记录全自动解析导入 (Folder Ingestion)
若你有过往导出的聊天记录，可在【导入建档】时直接拖入文件夹（支持包含多个 CSV / TXT / JSON 的复杂目录）：
- **多源归一化**：自动兼容标准微信导出 CSV、带时间戳的纯文本 TXT 与 JSON 留痕格式；
- **时序对齐与去重**：自动按全局时间轴重新排序，按 MD5 差量算法剔除跨年份跨文件的重复记录；
- **会话切片与故事萃取**：自动聚合连击气泡，将长周期历史数据压缩蒸馏为最初的人物画像与事件清单。

## 沟通策略知识库扩展 (`knowledge/`)

系统内置了模块化的沟通策略库，存放于 `knowledge/` 目录中：

| 模块目录 | 策略主题 | 涵盖能力 |
| :--- | :--- | :--- |
| `knowledge/emotional/` | **情绪价值库** | 真诚认可、提供温暖且有效的情绪回音、降压软着陆 |
| `knowledge/dynamic/` | **关系推进库** | 场景松弛感、社交校准、聊天化被动为主动、初次互动破冰 |
| `knowledge/boundary/` | **边界护体库** | 体面拒绝、关系投入失衡判断与止损、理性化解冲突 |
| `knowledge/tactics/` | **单轮战术编排** | 实战话术编排器、巧妙接话技巧、尴尬化解救场 |

### 如何自定义扩充：
只需在对应子目录下创建自定义 Markdown 文档（如行业术语指南、商务谈判技巧、个性调侃库等）。生成引擎在产出右栏的 3 档【微调提升】卡片时，会自动引入策略库进行微调升级。

## 大模型接入与运行模式

| 运行模式 | 说明 | 适用场景 |
| :--- | :--- | :--- |
| **模式 1：AI 智能体直接接管 (推荐)** | 在 Antigravity、Cursor 或 Claude Code 等 AI 助手中直接运行 `python3 app.py`。大模型通过本地 `GET /api/poll` 与 `POST /api/inject_options` 全程感知并推送建议。**零 Key 成本，即开即用**。 | 日常在 AI 编程环境中使用 |
| **模式 2：离线启发式引擎 (默认)** | 内置多主题语义分类与动态回声接话器。零网络依赖、毫秒级响应、不花一分钱。 | 脱离大模型环境独立运行 |
| **模式 3：商业大模型 API 接入** | 复制 `.env.example` 为 `.env`，填入 `LLM_API_KEY`（支持 DeepSeek / OpenAI / Moonshot 等兼容接口），后台自动调用云端模型生成。 | 独立运行且希望使用指定商用大模型 |

## 常见问题

- **点击【抓取最新】提示“目标不符”？**  
  内置安全拦截：若微信停留在其他群聊或好友窗口，系统会拒绝抓取，避免串味污染档案。切回目标好友窗口即可。
- **拖拽窗口位置？**  
  按住顶栏空白处或微缩胶囊面板即可在屏幕任意位置平滑拖拽。
