# 侧写 (Cexie)

> **macOS 微信桌面辅助副驾驶 · 极简透明悬浮窗 · 智能高情商回复生成**

「侧写」是一款常驻于 macOS 桌面边缘的极简透明悬浮窗工具。在与朋友聊天时，点击即可一键抓取微信对话上下文，并瞬间生成 4 条自然、高情商的回复建议。单击任意卡片即可复制，无键盘冲突，不修改微信客户端。

---

## 核心亮点

- **极简自适应 HUD**：宽度固定 430px，高度随文字内容紧密自适应，底端零留白；点击右上角【折叠】秒缩为 180×36px 边缘微型小胶囊。
- **全鼠标单击即复制 (Click-to-Copy)**：单击任意推荐卡片瞬间写入剪贴板并附带发光反馈，回到微信直接 `Cmd+V` 粘贴发送，零按键冲突。
- **4 条情景化回复 + 本轮洞察**：每次生成 4 条切入角度各不相同的回复，并附 2~4 条洞察（对方没说出口的意思、要避开的雷、值得接的点等）；卡片与洞察的标签都由模型按当轮对话现起，不套固定模板。
- **本地沙盒记忆**：以微信备注为独立目录隔离（`data/contacts/{备注}/`）；窗口截图与整屏 OCR 结果仅在内存与私有临时目录中处理、用完即删，记忆库只保留逐句事实摘录（详见下文「隐私说明」）。
- **灵活的驱动模式**：内置离线高情商启发式引擎；同时支持在 AI 对话框（如 Cursor / Antigravity / Claude Code）内直接接管，或通过 `.env` 接入商业大模型。

## 快速开始

### 1. 环境准备
- 系统：**macOS 12.0+** (支持 Apple Silicon 与 Intel 芯片)
- 环境：**Python 3.10+**，macOS 官方 WeChat 客户端

### 2. 安装与启动
```bash
# 克隆仓库并安装依赖
git clone https://github.com/pocui2333/cexie.git
cd cexie
pip install -r requirements.txt

# 启动程序
python3 app.py
```

> **注意 (首次启动系统权限)**：  
> 首次运行时，macOS 会申请权限，请前往 **系统设置 -> 隐私与安全性**：  
> 1. **屏幕录制**：允许当前终端 (Terminal / iTerm / VSCode) 与 Python；  
> 2. **辅助功能**：允许当前终端与 Python。

## 设置你自己的人设

生成回复时的身份、地域口语、职业知识边界、口头禅全部来自 `data/ego/profile.md`，代码中不预设任何人设：

```bash
cp data/ego/profile.example.md data/ego/profile.md   # 然后按自己的真实情况填写
```

全局禁用词、句长与语气基调在 `data/ego/rules.json` 中配置；每个好友目录下的 `rules.json` 可以覆盖全局设置（禁用词取并集）。

## 日常使用

1. **抓取与生成**：在微信中打开目标好友聊天窗，点击悬浮窗上的 **【抓取最新】**，几秒内完成识别与记忆沉淀，4 条回复建议在后台生成完毕后自动刷新（按钮显示「生成中...」；接入大模型时通常 5~15 秒，离线引擎接近即时）；
2. **复制与发送**：鼠标单击中意的卡片（卡片高亮并提示已复制），在微信输入框按 `Cmd+V` 粘贴发送；
3. **窗口折叠**：点击顶栏 **【折叠】** 收起为微缩胶囊，点击胶囊上的 **【展开】** 恢复全貌；
4. **新建好友档案**：点击顶栏 **【导入建档】**，填写微信备注名与自由描述（如“大学室友，说话互损，多用短句，别整客套话”），提交即可即时创建沙盒。

## 记忆沉淀与历史记录导入

```text
微信窗口截图 ──► [ 本地 Vision OCR / 气泡归属 / 标题栏核验联系人 ] ──► [ 增量指纹去重 ]
(私有临时目录，解析后即删)                                                   │
                                                                             ▼
                                         [ 实体与主题提炼，按「我 / 对方」逐句记录事实 ]
                                                                             │
                                  ┌──────────────────────────────────────────┴──────────┐
                                  ▼                                                     ▼
                         episodes.md (事实故事流)                              index.db (实体倒排索引)
```

### 1. 实时增量沉淀
- 每次抓取（手动或自动循环）都会先核验微信标题栏的联系人：**识别不到或与目标备注不一致时直接拒绝抓取**，绝不把别人的聊天写进当前档案；
- 通过沙盒内 `checkpoint.json` 的消息指纹去重，同一屏反复抓取也只记录一次；
- 区分「我说的」与「对方说的」，按先后顺序追加写入 `episodes.md` 并入库 `index.db`。

### 隐私说明
- 截图只写入当前用户私有（0700）的临时目录，解析结束立即删除；
- `episodes.md` / `index.db` 中会保留**逐句聊天摘录**（用于回扣记忆与模仿你的说话风格），请勿将 `data/contacts/` 同步到公开位置（已在 `.gitignore` 中排除）；
- 配置了 `LLM_API_KEY` 时，当前屏幕的聊天文字、联系人画像与相关历史摘录会发送给你配置的大模型服务商；聊天中出现的专有名词会查询百度百科，推断出的对方城市会查询 wttr.in 天气；
- 只有显式配置 `LLM_VISION_MODEL` 时才会把图片气泡上传给多模态模型，否则仅用 macOS 本地 Vision 粗分类；
- 本地 HTTP 服务只监听 `127.0.0.1`，并拒绝来自其他网页（Origin）与非本机 Host 的请求。

### 2. 历史聊天记录全自动解析导入 (Folder Ingestion)
若你有过往导出的聊天记录，可在【导入建档】时直接拖入文件夹（支持包含多个 CSV / TXT / JSON 的复杂目录）：
- **多源归一化**：自动兼容标准微信导出 CSV、带时间戳的纯文本 TXT 与 JSON 留痕格式；
- **时序对齐与去重**：自动按全局时间轴重新排序，按 MD5 差量算法剔除跨年份跨文件的重复记录；
- **会话切片与故事萃取**：自动聚合连击气泡，将长周期历史数据压缩蒸馏为最初的人物画像与事件清单。

## 沟通策略知识库 (`knowledge/playbooks.json`)

内置的情景微策略卡（情绪价值、关系推进、边界处理、单轮战术等）统一存放在 `knowledge/playbooks.json`。生成时会按对方消息命中触发词最多的一张卡片，作为右栏【微调提升】的策略参考。

### 如何自定义扩充
在【导入建档】的知识库页签中粘贴文章或填入本地 `.md` / `.txt` 文件路径（≤1MB），AI 会自动提炼为一张新的策略卡并即时生效（需配置 `LLM_API_KEY`）。

## 大模型接入与运行模式

| 运行模式 | 说明 | 适用场景 |
| :--- | :--- | :--- |
| **模式 1：AI 智能体直接接管 (推荐)** | 在 Antigravity、Cursor 或 Claude Code 等 AI 助手中直接运行 `python3 app.py`。大模型通过本地 `GET /api/poll` 与 `POST /api/inject_options` 全程感知并推送建议。**零 Key 成本，即开即用**。 | 日常在 AI 编程环境中使用 |
| **模式 2：离线启发式引擎 (默认)** | 内置多主题语义分类与动态回声接话器。零网络依赖、毫秒级响应、不花一分钱。 | 脱离大模型环境独立运行 |
| **模式 3：商业大模型 API 接入** | 复制 `.env.example` 为 `.env`，填入 `LLM_API_KEY`（支持 DeepSeek / OpenAI / Moonshot 等兼容接口），后台自动调用云端模型生成。 | 独立运行且希望使用指定商用大模型 |

## 常见问题

- **点击【抓取最新】提示“目标不符”？**  
  内置安全拦截：若微信停留在其他群聊或好友窗口、或标题栏联系人名未能识别，系统会拒绝抓取，避免串味污染档案。切回目标好友窗口后重试即可；若偶尔因 OCR 错字误拦，再点一次即可。
- **拖拽窗口位置？**  
  按住顶栏空白处或微缩胶囊面板即可在屏幕任意位置平滑拖拽。
